06 · Motion Rules

Motion establishes hierarchy on load and confirms interaction. Strictly NO decorative parallax, typewriter effects, or cursor tracking.

Animation Specifications

  • Reveal on Scroll: Only opacity: 0 → 1 and translateY(12px) → 0.
  • Timing: 450ms with cubic-bezier(0.16, 1, 0.3, 1) (ease-out).
  • Hover States: Cards lift -2px. Table arrows nudge 3px right. No soft drop shadows, only a slightly darker border.
  • Accessibility: CSS utilizes @media (prefers-reduced-motion: reduce) to disable transitions instantly.

6. Developer "10-Line Brand Rules"

1. NO soft drop shadows (box-shadow). Use 1px solid #E3DED3 for borders.
2. NO default blue for links. Use Deep Teal (#0F5B5B).
3. NO border radii above 6px. Keep corners sharp (2px) or slightly rounded (6px).
4. ONLY use Signal Amber (#C8762B) for data, highlights in diagrams, and stats.
5. Layouts MUST adhere strictly to the asymmetric 4-col / 8-col desktop grid.
6. Display typography (Fraunces H1/H2) MUST have -0.02em tracking applied.
7. Data labels MUST be uppercase IBM Plex Mono with 0.05em tracking.
8. Motion is limited to 450ms ease-out translateY reveals. Zero parallax.
9. Avoid pure black. Use Ink (#0E1A2B) for maximum depth and contrast.
10. Ensure Paper background (#F7F5F0) spans full bleed unless in dark mode sections.
