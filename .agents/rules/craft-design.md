# Bespoke Human Design & Editorial Principles

This project adheres to a strict editorial design system inspired by McKinsey/BCG insights reports and high-craft software engineering (Stripe Press, Linear, Pentagram).

## Forbidden AI Web Tropes (Never Generate)
1. **No SaaS Glow / Neon**: Never use dark neon gradients, cyan/purple glows (`from-purple-500 to-indigo-500`), or blurred backdrop glow spheres.
2. **No Generic 3-Card Symmetrical Grids**: Avoid identical floating rounded cards with centered icons in pastel circles. Favor asymmetric splits (7/5, 8/4) and structured data tables.
3. **No Empty Fluff / Buzzwords**: Never use "Unleash", "Streamline", "Revolutionize", "Game-changer", or vague marketing claims. Keep copy grounded in real artifacts, measured outcomes, and technical precision.
4. **No Generic Stock Icons**: Avoid generic Lucide/Feather icon soup. Use bespoke SVG process diagrams, architecture schematics, and tabular metadata.
5. **No Flat Sterile Digital Surfaces**: Retain tactile paper grain, warm off-white `#F7F5F0`, and deep `#0E1A2B` ink contrast.

## Mandatory Editorial Design Standards
1. **Typography Hierarchy**:
   - Display Headings: Fraunces (warm editorial serif with character).
   - Body & Flow: Inter Tight (clean, legible grotesk).
   - Data & Technical Labels: IBM Plex Mono (monospaced metadata, timeframes, status codes, tags).
2. **Consulting Presentation Frameworks**:
   - McKinsey SCR (Situation, Complication, Resolution) summary boxes.
   - Structured before/after architecture flow diagrams.
   - Distinct tags separated by middots (`·`) rather than loud colored pill chips.
3. **Micro-Interactions**:
   - Restrained magnetic attraction on primary actions.
   - Weighted inertial scrolling (`lenis`).
   - Tactile paper tooth overlay.
   - Minimalist monospace toast feedback.
